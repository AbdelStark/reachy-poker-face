# Security and privacy

This is entertainment, not lie detection. Do not infer dishonesty, identity, health, or mental state from its output. Do not use it for screening or consequential decisions.

The app sends statement text and a small game state to the configured relay, which sends them to TypeSafe for a Jev judgment. The relay does not intentionally log request bodies or API keys. No statement text is saved to browser storage by this app. Numeric settings and, only if the player types a nickname, nickname scores are saved in browser local storage; the UI can clear those scores. The unnamed session score stays in the current tab. A browser speech-recognition provider may process device-microphone audio off-device when the user presses **Use browser microphone**; this is independent of the TypeSafe request.

The optional robot-audio path is off by default and needs separate consent from everyone audible for each round. The browser holds at most 15 seconds of robot-stream samples in tab memory, resamples to 16 kHz PCM, and sends it only to an explicitly configured numeric-loopback ASR companion with a separate bearer token. Unchecking consent or leaving discards capture and aborts a pending request; an already-delivered request cannot be retracted. The companion does not log or store PCM or transcripts and accepts only bounded, finite raw PCM, but the browser, OS, and local model runtime may retain transient copies. Only returned statement text and delivery buckets enter the Jev request. Do not expose the ASR companion beyond loopback; it lacks the protections required for a public service. No robot microphone or actual ASR model has been evaluated here.

Optional robot-speaker output is separately off by default. Only complete, fixed game lines are sent to the authenticated numeric-loopback TTS companion; player statements are not. The companion invokes host-installed eSpeak NG and FFmpeg without a shell and returns bounded PCM16 WAV. The browser validates the WAV before using the pinned SDK's audio upload/play API. A reset, microphone capture, mode change, or app exit aborts pending TTS and requests cancellation of an uploaded clip, but the SDK does not acknowledge that robot playback has ended or that cancellation silenced the speaker. An upload in progress may finish after cancellation; the app then requests cancellation for its returned ID before invoking play. No live speaker, latency, cancellation, or voice-quality claim has been verified. Do not expose the companion beyond loopback or treat its token as a public-service credential.

Completed-round traces are kept in tab memory only (up to 100), with statement text excluded by default. Including text needs separate per-round consent before the round starts; the checkbox resets each round. Trace files never include nicknames, audio, or video. Once exported, files can be retained or shared outside the app, so inspect them before doing so. The calibration reader reports only aggregate numbers and model IDs; it does not print statement text.

Clip capture is off by default and requires a fresh consent checkbox for each round. It records canvas video only, without an audio track or statement text; recording stops after 30 seconds and the blob remains in browser memory until download or discard. Do not check the box without consent from everyone visible. An exported clip is then under the downloader's control; this app cannot revoke a file they have saved or shared.

Keep the TypeSafe API key server-side. The development relay requires a strong bearer token, checks an exact browser origin, limits body size and concurrent requests, and returns generic upstream errors. Those controls are not a full public-service deployment: add TLS, operational rate limits, abuse controls, secret rotation, and cost monitoring before exposing a relay to the internet. An origin header is not authentication; the bearer token is required even when the origin matches. Do not share the token with untrusted clients.

Robot motion is expressive only. It uses the SDK target interface, but its ranges, neutral pose, physical antenna-tap detection, and leave behavior require a real-device safety check before unattended use. Stop the app if a motion or actuator behaves unexpectedly.
